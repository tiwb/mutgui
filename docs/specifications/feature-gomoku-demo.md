## 设计方案

### 范围

- 单页面棋盘视图
- 15x15 棋盘
- 黑白轮流落子
- 连成五子即获胜
- 无禁手、无换手规则、无房间系统

### 数据模型

使用 `GomokuGame` 维护：

- `board`：15x15 棋盘，空位或黑/白棋
- `current_stone`：当前轮到谁
- `winner`：胜方
- `winning_line`：用于高亮的连五坐标
- `history`：落子历史，支持悔棋
- `ai_stones`：当前启用 AI 的棋方

### 交互约定

- 点击空位直接落子
- 已落子、胜负已出、或轮到 AI 思考时，棋盘不可手动点击
- 提供 `重开`、`悔棋`、`切黑AI` / `切白AI` 按钮
- AI 启用后，在轮到对应棋方时自动延迟一步执行

### AI 策略

保持“合理但不强”：

1. 自己有直接成五机会时，立即取胜
2. 对手有直接成五机会时，优先堵住
3. 其他情况优先在已有棋子附近、兼顾自己连线和对手威胁

### 视图

使用普通 `div` / `span` + CSS grid 绘制棋盘，不新增前端组件：

- 棋盘每格可点击
- 黑白棋用文本字符显示
- 最后一手与胜利连线有高亮
- 棋盘外层支持横向滚动，保证手机端仍可操作
